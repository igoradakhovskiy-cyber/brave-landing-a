# BRAVE CAPITAL — лендинг «Зарплата власника» (сегмент A)

Посадочна сторінка для власників бізнесу в Україні: калькулятор зарплати власника → 20-хвилинний розбір з радником.

Один файл `index.html` (стилі й скрипти всередині) + зображення в `assets/`.

## Режими перегляду

| Адреса | Що показує |
|---|---|
| `/` | Основна версія |
| `/?story=stock` | Сюжет для товарного бізнесу й виробництва |
| `/?story=service` | Сюжет для послуг і агенцій |
| `/?review=1` | Жовтим підсвічено факти, які ще треба підтвердити |

## Аналітика

- Meta Pixel `1669140901889164`: `PageView` при завантаженні, стандартна подія `Lead` при відправці будь-якої форми (з `eventID` для майбутньої дедуплікації з CAPI).
- Усі події також ідуть у `dataLayer`.

## Що ще не підключено

- Заявки поки нікуди не надсилаються: `SUBMIT_URL` у `index.html` порожній, заявка лише пишеться в консоль браузера. Потрібен вебхук CRM.
